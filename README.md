## 🔬 Engineering workflow

```text
Requirements and constraints
        ↓
Datasheet and interface review
        ↓
Schematic design
        ↓
ERC and electrical verification
        ↓
PCB layout and DRC
        ↓
Firmware modules and drivers
        ↓
Block-level hardware testing
        ↓
System integration
        ↓
Measurement, debugging, and documentation
        ↓
Design improvement
```

My engineering principles:

- **Understand the complete system first** — interfaces, constraints, failure modes, and operating conditions matter more than isolated code.
- **Design for verification** — logs, test points, reproducible builds, and clear acceptance criteria reduce guesswork.
- **Prefer safe failure modes** — timeouts, validation, recovery paths, and conservative hardware assumptions are part of the design.
- **Document decisions** — a project should remain understandable after the prototype works.
- **Optimize after measuring** — performance improvements should be based on evidence from real tests.
